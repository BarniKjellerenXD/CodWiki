CodWiki Desktop v1.3.1 groups navigation by map and supports the website's companion workflow.

- One category per map, with Guide first and that map's puzzle tools below. Older saved layouts are regrouped automatically.
- Searchable, collapsible sidebar covering all six maps and thirteen tools.
- Reading themes carry through to the desktop shell; application and reading settings have distinct controls.
- Support for saved quest checklists, Quick Steps and Full Details, and solver return links in the website.
- Super Easter Egg access stays on the homepage.
- Custom labels, hidden entries, shortcut bindings and tool ordering remain saved.

Download the Setup `.exe` to install the Windows app, or extract the portable `.zip` and run CodWiki. Your existing settings are preserved.
