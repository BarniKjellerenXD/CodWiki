# CodWiki

CodWiki is a Call of Duty Zombies reference app. Players use it alongside a match to understand map setup, equipment, main quests, side Easter eggs and puzzle steps. It serves first-time solvers who need clear explanations and experienced players who need a quick reference.

Guides provide the complete sequence, prerequisites, player-count requirements, locations, success cues and recovery instructions. Quick Parts supports following a run; Full Details provides the explanations and illustrated references. Map-specific tools link back to the relevant guide phase.

Tools should solve a concrete problem during play: identify a symbol, translate an observed pattern, remember a changing sequence or find a difficult location. Fixed instructions belong in the guide. A generic requirements or upgrade-route checklist does not earn a separate tool when it only repeats the guide.

Use recognizable gameplay images and symbol references with source credits. Explain what to look for, what to do with the result and how to recover from an incorrect observation. Distinguish recorded observations from actions confirmed in the game. Preserve existing saved progress and bookmarks when expanding guides.

The app uses its established charcoal-and-gold guide and tool components, with responsive layouts, visible keyboard focus, readable text and images that can be enlarged. New content extends that system. Guidance must stay useful on a phone while a match is in progress.

The homepage makes the full catalogue easy to reach through a sticky game navigation rail on wide screens and a compact game selector on phones. Covers should invite players into a recognizable map with atmospheric game imagery. Keep cover artwork independent of instructional guide images; record its sources in [the homepage artwork manifest](docs/home-artwork.json).

Content draws on multiple community sources, explicitly distinguishes game versions where mechanics differ and identifies review limits. Website checks and source review are not an in-game playthrough.

The current expansion's scope, chosen helpers and validation are recorded in [the Zombies Chronicles plan](docs/chronicles-plan.md).
